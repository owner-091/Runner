# 입으로 달려라! (Mouth Runner)

직접 학습한 CNN이 웹캠으로 입모양을 읽어 기사 캐릭터를 조종하는 횡스크롤 러닝 게임입니다.
사전 학습 모델이나 외부 라이브러리 없이, 브라우저에서 CNN을 직접 계산하고 학습합니다.

| 입모양 | CNN 분류 | 게임 동작 |
|---|---|---|
| 입 다물기 | `closed` | 달리기 (1초 유지하면 시작·재시작) |
| 입 벌리기 | `open` | 점프 |
| 이 보이게 웃기 | `teeth` | 수그리기 (공중에서는 빨리 떨어지기) |

키보드: Space/↑ 점프 · ↓ 수그리기 · Enter 시작

## 처음 해 보기 (약 5분)

1. **내 입모양 학습하기**(`collect.html`)를 엽니다.
2. 노란 박스에 입을 맞추고, 세 가지 입모양을 각각 **연속 촬영**합니다 (분류마다 60장 이상 권장).
3. **학습 시작** → 1~2분 뒤 **이 모델로 게임하기**를 누르면 새 탭에서 게임이 열립니다.

## 내 컴퓨터에서 실행

- 크롬(또는 엣지)에서 `index.html`이나 `collect.html`을 더블클릭해 열면 웹캠까지 동작합니다.
- 다른 방법: 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속.

## 파일 구성

```
index.html            게임 화면
collect.html          내 입모양 학습하기 (사진 모으기 + 브라우저 학습)
assets/knight.png     기사 캐릭터 (16×24 픽셀 9칸: 점프, 대기 2, 착지, 달리기 4, 수그리기)
css/style.css         디자인
js/cnn.js             CNN 계산 (합성곱·풀링·완전연결을 순수 자바스크립트로 구현)
js/train.js           CNN 학습 (역전파 + Adam, 코랩 노트북과 같은 구조)
js/mouth-cam.js       웹캠 → 입 영역 64×64 → 예측 → 흔들림 줄이기 → 명령
js/game.js            게임 규칙과 그리기
js/collect.js         학습 페이지
model/mouth_model.js  사이트 기본 모델 (코랩 또는 학습 페이지에서 내려받은 파일로 교체)
```

## 모델을 사이트에 넣기

- 학습 페이지의 **mouth_model.js 내려받기** 또는 코랩 노트북 마지막 셀이 만든 `mouth_model.js`로
  `model/mouth_model.js`를 덮어쓰면, 처음 방문한 사람도 그 모델로 게임합니다.
- "이 모델로 게임하기"로 저장한 모델은 그 브라우저에만 저장되며, 게임 화면에서 사이트 모델과 바꿔 쓸 수 있습니다.

## 개인정보

- 웹캠 영상은 브라우저 안에서만 계산되며 서버로 보내지 않습니다.
- 학습 사진이 들어 있는 노트북(`.ipynb`)과 `mouth_data_*.json`은 **이 저장소에 올리지 않습니다.**
  `model/mouth_model.js`에는 가중치 숫자만 들어 있습니다.
